# Translating Envelope

Envelope's interface is available in **French** and **English**, both maintained by the project team. Other languages are welcome from the community. Thank you for helping!

## How it works

- Every text of the interface lives in `src/locales/<language>/<screen>.json` (one file per screen, e.g. `sidebar.json`, `settings.json`). English (`en`) is the **source language**: keys and reference texts are in English.
- Errors raised by the Rust engine are translated too: they live in `src/locales/<language>/errors.json` under `rust.<code>`.
- The language follows the system by default; users can change it in *Settings › Appearance › Language*.
- Texts missing in a language fall back to English, so an incomplete translation never breaks the app.
- `docs/translations/STATUS.md` (generated by `pnpm i18n:status`) lists, for each language, the completion rate and the missing texts. A language is shipped once it is **at least 90 % complete**.

## Add a language

1. Fork the repository and create a branch.
2. Copy `src/locales/en/` to `src/locales/<code>/` (a two-letter [ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) code, e.g. `de`, `es`).
3. Translate the **values** in every file. Never change the keys.
4. Register the language in `LANGUAGES` in `src/lib/i18n.ts` (code and name written in that language, e.g. `{ code: "de", label: "Deutsch" }`).
5. Try it: `pnpm install && pnpm dev`, then open `http://localhost:1420/?lang=<code>` (the demo mailbox needs no account).
6. Run `pnpm i18n:status` and commit the updated `docs/translations/STATUS.md`.
7. Open a pull request. Mention the system(s) you tested on.

To **fix a translation**, edit the value in the language's JSON file and open a pull request.

## Rules

- **Variables** such as `{{name}}` or `{{count}}` are replaced at runtime: keep them exactly as written (you may move them). Do not translate what is inside the braces.
- **Plurals** use `_one` / `_other` suffixes (`items_one`, `items_other`) with `{{count}}`. Languages with more plural forms add the extra categories of [CLDR](https://cldr.unicode.org/index/cldr-spec/plural-rules) (`_zero`, `_two`, `_few`, `_many`). Provide every form your language needs.
- **Markup** such as `<code>…</code>` or `<mono>…</mono>` inside a text must stay: it is turned into the matching element.
- **Tone**: address the user directly and politely (French: *vous*). Keep sentences short; buttons and menu items are a few words.
- **Do not translate** product and technical names: Envelope, IMAP, SMTP, OAuth2, MCP, mbox, Maildir, Thunderbird, FileVault, BitLocker…
- **Keep it faithful to the English meaning**, then check the screen: a text that is much longer than the English may not fit a button.
- Dates, numbers and sizes are formatted by the system (`Intl`), nothing to translate there.

## Glossary

Use the same word everywhere for the same thing.

| English | Meaning | French |
|---|---|---|
| conversation | a thread of related messages | conversation |
| star / starred | mark a conversation to follow it | suivre / suivis |
| archive | move to the archive folder on the server | archiver |
| archive on this computer | store a copy only on this computer, outside any server | archiver sur cet ordinateur |
| local folder | folder that exists only on this computer | dossier local |
| snooze | hide a conversation until a date | reporter |
| follow-up reminder | remind me if nobody replies | relance |
| reminder | snooze or follow-up | rappel |
| rule | automatic actions on new messages | règle |
| sender / alias | an address you can send from | expéditeur / alias |
| draft | an unsent message | brouillon |
| template | a saved message to reuse | modèle |
| lock | ask for authentication to open the app | verrouillage |
| smart views | Unread, With attachments, Reminders | vues intelligentes |
| agent / MCP server | lets an AI assistant read the mailbox, read-only | agent IA / serveur MCP |

## Checks

`pnpm test` verifies that English and French have the same texts and variables, and that every text used in the code (and every error code of the engine) exists. Contributed languages are checked for the status report only; a mismatching variable is the most common mistake, so please double-check them.
